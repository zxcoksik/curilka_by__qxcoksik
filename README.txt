КАТАЛОГ — ФОТОГРАФИИ В ОДНОМ ФАЙЛЕ

Структура:
index.html
style.css
products.js
photos.js
app.js

Все фотографии каталога собраны в один файл photos.js.
Отдельной папки images больше нет.

Важно: photos.js может быть большим, потому что внутри находятся сами изображения.
Для GitHub/HTMLPreview это удобно по количеству файлов, но загрузка каталога может быть тяжелее.
